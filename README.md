# Pamsampson Website

A simple, clean, and responsive personal website to host pictures and text.

## Features

- 📸 Photo gallery with descriptions
- 📝 Text sections for content
- 📱 Fully responsive design (works on mobile, tablet, desktop)
- 🎨 Modern, clean styling
- ⚡ Easy to customize

## How to Use

1. **Edit the content**: Open `index.html` in a text editor and update:
   - The header title and subtitle
   - Section text (Home, About, etc.)
   - Photo gallery items

2. **Add your photos**:
   - Replace the placeholder image URLs with your own
   - You can store images in a folder like `/images` in this repository
   - Update the `src` attribute in the HTML to point to your images

3. **Deploy to GitHub Pages**:
   - Go to your repository Settings → Pages
   - Select "Deploy from a branch"
   - Choose `main` branch and `/root` folder
   - Your site will be live at `https://psampson00.github.io/pamsampson`

## Customization Tips

- **Colors**: Change the gradient colors in the `<style>` section (currently purple/blue)
- **Fonts**: Modify the `font-family` in the CSS
- **Layout**: Adjust the gallery grid by changing `grid-template-columns`
- **Add sections**: Copy and paste the section structure to add more content
